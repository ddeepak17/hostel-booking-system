# PG / Hostel Room Booking System

Full-stack MERN hostel accommodation booking platform.

## Stack

Frontend: - React - Vite - Tailwind CSS - React Router - Axios

Backend: - Node.js - Express.js - MongoDB - Mongoose - JWT - bcrypt

## Roles

-   Customer
-   Property Owner
-   Super Admin
